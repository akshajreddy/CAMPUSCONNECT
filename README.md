# CampusConnect – Modern Startup Landing Page

> **"Everything Campus, All in One Place."**  
> An all-in-one campus platform bringing essential student activities and services together for college students and universities.

---

## 🎓 About CampusConnect

College students currently rely on dozens of chaotic WhatsApp groups, miscellaneous Discord servers, and disorganized bulletin boards to track campus events, club activities, textbook exchanges, lost belongings, and roommate searches. This creates endless noise, wasted hours, and missed opportunities.

**CampusConnect** solves this fragmentation with a modern, verified, student-first platform connecting everything campus life requires under one roof.

## 🚀 How to Run Locally

### Option 1: Direct Browser Launch
Simply double-click `index.html` or drag it into any modern web browser (Google Chrome, Microsoft Edge, Safari, Firefox).

### Option 2: 1-Click Windows Launcher
Double-click `start.bat` in this folder. It will start a local Python HTTP server and automatically open `http://localhost:3000` in your default browser.

### Option 3: Command Line (Python)
```bash
python serve.py 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Tech Stack & Architecture

- **React 18**: Component-driven architecture, state management (`useState`, `useEffect`, `useMemo`), hooks, and interactive modal system.
- **Tailwind CSS 3.4**: Custom color palette (Royal Blue `#2563eb`, Subtle Purple `#7c3aed`, Deep Slate Navy `#0f172a`), mesh gradients, smooth transitions, and glassmorphism.
- **Plus Jakarta Sans & Inter Fonts**: Modern, clean, tech-forward typography.
- **Inline SVG Icon System**: Zero external icon font latency; completely self-contained and renders offline immediately.
- **Babel Standalone**: Compiles React JSX client-side seamlessly.
